`SKILL.md` is an unmodified copy of the `mobile-design` skill from
https://github.com/nylo-core/claude-code (`skills/mobile-design/SKILL.md`,
commit 1305d3f9d4de9474f88a87b384165e62baf805f6, 2026-04-11), MIT licensed;
see `LICENSE` in this folder.

To update it, copy the file again from that repository and record the new
commit here. Keep this project's own rules out of `SKILL.md`, so it stays an
exact copy.

In this project the skill applies to the Flutter app in `apps/mobile`. As
the skill itself says, the project's design system comes first: colours,
spacing and radii in `apps/mobile/lib/core/design/tokens.dart`, the theme in
`theme.dart`, the Manrope typeface, and the brand described in
`docs/architecture/mobile-app.md`.
